# Triage labels

The engineering skills use five canonical triage roles. Apply the corresponding label in Linear.

| Canonical role | Linear label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Needs evaluation |
| `needs-info` | `needs-info` | Waiting for the reporter |
| `ready-for-agent` | `ready-for-agent` | Specified for agent implementation |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

If a skill refers to a triage role, use the label in the right-hand column. Add missing labels in Linear before applying them.
